# openlab-perception-fe

여러 가정에서 동시에 벌어지는 상황을 3D 지구본 위에 띄우고, 각 가정의 4채널
카메라 · 오디오 · 센서 신호를 관객에게 보여주는 전시용 무인 순환 데모.
아무도 만지지 않으면 알아서 한 곳으로 들어갔다 나오며 계속 순환한다.

## 실행

```bash
npm install
npm run dev
```

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | 정적 파일로 빌드 (전시 기계에 폴더째 복사) |
| `npm run test` | 단위 테스트 |
| `npm run test:e2e` | 실제 브라우저 스모크 |
| `npm run typecheck` | 타입 검사 |

## 구조

| 디렉터리 | 책임 |
| --- | --- |
| `src/core/` | 데이터 계약, 타임라인 클럭, 시나리오 로더. DOM을 모른다 |
| `src/media/` | 프레임·오디오 공급자. 인터페이스 뒤에 구현이 갈린다 |
| `src/scenario/` | 한 가정에 들어갔을 때의 화면 |
| `src/world/` | 지구본과 무인 순환. **바깥 의존이 시나리오 타입 하나뿐이라 떼어낼 수 있다** |
| `scenarios/` | 시나리오 데이터. JSON 하나를 넣으면 코드 수정 없이 합류한다 |

## 카메라

`livingroom` · `entry` · `bedroom` · `rvc` (로봇청소기 시점, 이동형)

## 교체 지점

실제 데이터·영상이 준비되면 아래 두 곳만 갈아끼운다. 뷰 코드는 바뀌지 않는다.

- `src/core/reasoning-source.ts` — 기본은 시나리오 JSON 재생. `slice`는 반드시 동기여야 한다
- `src/media/frame-source.ts` — 기본은 캔버스 프로시저 렌더. 실영상이 오면 여기로

두 곳 모두 팩토리를 주입받으므로 `usePlayback`·`CameraPanel`을 수정할 필요가 없다.

## 제약

- 전시장 PC에서 **완전 오프라인** 동작 (CDN·외부 폰트·외부 텍스처 금지)
- 며칠간 무인 구동. 시나리오가 바뀔 때마다 자원을 해제한다
- 시나리오 하나가 잘못돼도 나머지로 계속 돈다. 검은 화면은 금지

## 좌표 규약

지구본의 위경도 변환은 `src/world/geo.ts` 한 곳에만 있다. 위도·경도는 도(degree),
+Y가 북극, 경도가 커지면 -Z 쪽으로 돈다. 이 규약은 `tests/world/geo.test.ts`가
못 박고 있으므로, 다른 코드베이스로 옮겨 핀 위치가 틀어지면 그 테스트부터 돌릴 것.
